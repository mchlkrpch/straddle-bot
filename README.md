# BTC на Deribit · Задание 3

Купленный ATM-стрэддл и сетка на BTC-перпетуале. [Отчёт в PDF](report/report.pdf) содержит формулы, сравнение стратегий, разбор издержек и неудачных циклов. Весь расчёт выполняется локально на включённой истории Deribit.

## Воспроизведение одной командой

Из корня скачанного репозитория, с Python 3.10 или новее:

```sh
python3 reproduce.py
```

Используется стандартная библиотека Python. Данные уже включены, API-ключи и компилятор не требуются. Команда распакует данные во временную папку, заново исполнит стратегии, сверит метрики с контрольными значениями и запишет результат в `results/`. Успешный прогон заканчивается сообщением «Проверено: пять счетов, годовые результаты и 1049 дневных отметок капитала».

## Какие результаты сравниваются

**Исходный эксперимент задания 3**, с 1 мая 2022 года до 14 ноября 2026 года, использует общие даты опционного входа и одинаковые размеры для парного сравнения. CAGR связки составил +7,41%, чистого стрэддла +8,28%, грида −1,16%, стрэддла с пороговым дельта-хеджем −23,81%. Для четырёх конструкций команда дополнительно проверяет просадку, Sharpe и среднее худших 5% циклов.

**Итоговые боты отчёта** сравниваются при независимом старте с 150 000 USDC 1 января 2024 года. Конечная граница — 14 ноября 2026 года, 00:00 UTC. В таблице геометрическая годовая доходность всего счёта после модельных издержек.

| Стратегия | CAGR | Без лучшей кампании |
|---|---:|---:|
| Стрэддл + грид | +1,15% | +0,34% |
| Самостоятельный грид | +0,0016% | −0,0302% |
| Стрэддл + дельта-хедж | +0,79% | +0,20% |
| Тренд за 42 дня | +14,40% | +3,70% |
| Тренд + стрэддл с гридом, 50/50 | +8,17% | +2,46% |

Показатель **+16,68% годовых** относится к трендовому боту на полном периоде с мая 2022 года, при его исходной тейкерской комиссии 3,5 б.п. На этом интервале максимальная просадка составила 42,60%. При комиссии 5 б.п. его CAGR равен +15,97%. В CSV доходности записаны долями единицы, даты — в UTC.
